# Demo Script (about 3–5 minutes)

1. Start the application from Visual Studio.
2. Explain the dashboard metrics.
3. Open Products and search for an SKU or product name.
4. Demonstrate adding a product and explain required fields.
5. Edit the new product and change its stock count.
6. Show the low-stock filter and explain reorder levels.
7. Open Reports and explain inventory valuation by category.
8. If internet is available, demonstrate barcode lookup and explain that Open Food Facts is a public API with no API key required.
9. Briefly describe the database relationships: categories and suppliers can each be related to many products.
