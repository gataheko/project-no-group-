# Suggested Team Workflow

Use this as a planning template. Record only work that actually happened.

## Suggested milestones
1. Requirements and proposal
2. Database and models
3. Inventory features
4. API integration and reports
5. Testing and final presentation

## Suggested GitHub issues
- Create database models and seed data
- Build dashboard
- Implement product create/edit/archive
- Add search and sort
- Add low-stock and valuation reports
- Integrate Open Food Facts barcode lookup
- Test validation and error handling
- Update user guide and demo script

## Pull request expectations
- Use a feature branch for each assigned task.
- Open a pull request with a description and test evidence.
- Request a teammate review if working as a group.
- Merge only after review and tests.
