# Manual Testing Checklist

- [ ] App starts from Visual Studio with F5.
- [ ] Dashboard displays product count, low-stock count, and inventory value.
- [ ] Product list shows seeded example products.
- [ ] Search works for product name, SKU, and barcode.
- [ ] Sorting works by name, SKU, stock, and price.
- [ ] Add a product with valid information.
- [ ] Attempt to add a duplicate SKU and verify validation.
- [ ] Edit a product and confirm the changes persist.
- [ ] Archive a product and confirm it no longer appears in the active list.
- [ ] Low-stock filter shows only products at/below reorder level.
- [ ] Reports show totals by category.
- [ ] Barcode lookup works with internet and a known product barcode.
- [ ] Barcode lookup handles unknown barcode / no internet gracefully.
